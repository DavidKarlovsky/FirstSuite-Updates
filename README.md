# FirstSuite Updates

This public repository contains only update channel manifests and public release notes for FirstSuite.
The application and its source code are in a separate private repository. Downloading a release requires a GitHub account with access to that repository.

`channels/stable.json` is created after the first published stable release. `channels/beta.json` is created only after a published prerelease. A missing channel file means no release has been published for that channel.

Manifests are data only. They never contain executable instructions or download credentials.
